About the tools Information Fasttree: Fasttree is a software program that we use for it speed and efficiency in generating a phylogenetic tree. It takes as input an aligned nucleotide or protein sequence in FASTA or PHYLIP format. Fasttree is a special toolkit because it can handle large datasets with thousands of sequences. Despite the handling of long data, fasttree quickly constructs a phylogenetic tree and outputs it in Newick-format(.nwk), which is used for visualization tools. If you want to use Fasttree, you must do that via the command line, but it must be installed on your computer. For the install of fasttree see this link: https://morgannprice.github.io/fasttree/ Fasttree use an approximation of maximum likelihood method (ML). This means that it constructs phylogenetic trees while maintaining a balance between computational speed and accuracy. Fasttree supports different evolutionary models, such as GTR for DNA and WAG for proteins. It can also include gamma-disturbed rate variation for better branch length estimation. Although Fasttree is faster than Ml-based programs like RAxML or PhyML, it is slightly less accurate. However, Fasttree is a powerful tool to use for phylogenetic trees Information ETE toolkit: The ETE (Eniviroment for Tree Exploration) toolkit can be used for making phylogenetic tree. The tool assist in analyzing and visualizing of making phylogenetic trees. With this tool you can make small and big trees and it will visualize in professional way. The ETE-toolkit is python-based what is a common program-language for many programmers. We are using the ETE toolkit because it has extra functionalities with phylogenetic trees.
