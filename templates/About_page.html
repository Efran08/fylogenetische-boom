Information Fasttree:

Fasttree is a software program that we use for it speed and efficiency in generating a phylogenetic tree. It takes as input an aligned nucleotide or protein sequence in FASTA or PHYLIP format. Fasttree is a special toolkit because it can handle large datasets with thousands of sequences.

Despite the handling of long data, Fasttree quickly constructs a phylogenetic tree and outputs it in Newick-format(.nwk), which is used for visualization tools. If you want to use Fasttree, you must do that via the command line, but it must be installed on your computer. For the install of fasttree click this sentence.

Fasttree use an approximation of maximum likelihood method (ML). This means that it constructs phylogenetic trees while maintaining a balance between computational speed and accuracy. Fasttree supports different evolutionary models, such as GTR for DNA and WAG for proteins. It can also include gamma-disturbed rate variation for better branch length estimation.

Although Fasttree is faster than Ml-based programs like RAxML or PhyML, it is slightly less accurate. However, Fasttree is a powerful tool to use for phylogenetic trees

The options that are available for Fasttree are the speed, where a quicker made tree is less accurate, a slower tree is more accurate and the default speed is a balance between those. The parameter for the model is devided in nucleotides and proteins. For nucleotides you can choose between Jukes-Cantor or Generalized time-reversible. The Jukes-Cantor model is default for nucleotides and it works by a formula that calculates the distance. The formula goes as followed: d = -(3/4) log(1 - (4/3)p), where p is the proportion of non-gap positions that differ. For more information about the Jukes-Cantor model click this sentence.

The other model for nucleotides is the GTR model, which stands for generalised time reversible. The GTR model is more accurate than the Jukes-Canter model, but it is slower. The second model for proteins is Whelan & Goldman 2001 model. This model is more accurate than the JTT 1992 model, because the JTT 1992 model relies on assumptions that may lead to systematic errors and a discard of a large amount of information. The structure of the Whelan & Goldman 2001 model is similar to the JTT 1992 model but the Whelan & Goldman 2001 model applies the maximum likelihood values. This provides a better overall fit to the evolutionary process in globular proteins and may lead to more accurate phylogenetic tree estimates.

For more information about the Whelan & Goldman 2001 model, click here

The third and last model is Le and Gascuel 2008 model. This model is the most accurate model for the protein sequences. The LG 2008 model improved upon the WAG (Whelan and Goldman) 2001 model. The improvements in the LG 2008 model contains a bigger database then the WAG 2001 model uses. Important to note is that the LG 2008 model is better than WAG for 38 alignments but worse when there are only 2 alignments.

The last parameter to choose is the species name. You can choose between the extendend species name, which will show up as for instance: >NT_033779.5:c7795959-7791175 LKRSDH [organism=Drosophila melanogaster] [GeneID=34064] [chromosome=2L]. In this sentence information about the species, the gene, the protein and the chromosome is shown. If you choose for no extended species name, it will only show the organism.

Information ETE toolkit:

The ETE (Eniviroment for Tree Exploration) toolkit can be used for making phylogenetic tree. The tool assist in analyzing and visualizing of making phylogenetic trees. With this tool you can make small and big trees and it will visualize in professional way.

The ETE-toolkit is python-based what is a common program-language for many programmers. We are using the ETE toolkit because it has extra functionalities with phylogenetic trees. Example from a functionalitie: With the ETE toolkit you can compare two different phylogenetic trees and you can see what the relatives are between the two trees who are compared.
