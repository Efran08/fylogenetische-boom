How to use the Tool page:

Step 1, Choose your file:

1. First you need to select a file, which must be a FASTA or PHYLIP file and should include a header.

Step 2, Change the speed of creating a phylogenetic tree:

2. You can choose the speed of creating the phylogenetic tree. The only issue with this is that the higher the speed, the less accurate the pylogenetic tree will be.

Step 3, Type of Fasttree model:

3. Next you can choose which style of Fasttree you want to use. Each Fassttree method has his own qualities, so choose the one that you likes the most.

Step 4, Extended species name:

4. You can decide if you want to see the entire protein or nucleotide sequence. If you want that, it will cost more time to create a phylogenetic tree.

Step 5, Uploading:

5. Click on Upload if you fill up the steps here above.
